How do complimentary and lifetime access work?

If you have a Nudge+ code, redeem it through Apple using the option in Nudge+ Access.

Choose Redeem Nudge+ Code, or expand More access options when shown, and follow Apple’s instructions. Review the resulting access status and end or renewal date. Complimentary access can be time-limited; lifetime access is shown as Lifetime Nudge+ when verified.

Lifetime access does not automatically cancel a separate renewing subscription. Review Manage Subscription in Apple’s settings if both are active. A code is not a promise of eligibility or a general offer of free lifetime access. If redemption is unresolved, use Check Access when offered.
